<span class="operator-brand">Operator!</span> runs on two ideas: work is written down as **tickets**, and tickets move across a **kanban** board as agents pick them up and finish them.

- **[Tickets](/getting-started/tickets/)** — the unit of work. A markdown file describing one task for an agent, carrying an issue type that decides how the work is done.
- **[Kanban](/getting-started/concepts/kanban/)** — the board. Where tickets wait, get worked, and land when done. New to kanban? Start here.

Everything else — [agents](/getting-started/agents/), [providers](/getting-started/kanban/), [workflows](/workflows/) — builds on these two.
