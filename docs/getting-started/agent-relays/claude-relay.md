---

Operator includes a Claude-compatible embedded relay, catalogued as `claude-relay`. It carries structured agent events and control messages. Relay availability does not itself require Premium.

See the [relay reference](/relay/) for the protocol and configuration. Remote execution retains the launcher's relay and worktree limitations; a Premium license does not remove those compatibility checks.
